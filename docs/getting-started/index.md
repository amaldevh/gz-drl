# Getting started

Start with a local GzDRL installation, check that its packaged worlds and
plugins are available, then run a short simulation. The core workflow requires
Gazebo and Python; ROS is optional.

Read these pages in order:

```{toctree}
:maxdepth: 1

installation
verification
quickstart
```

After the quickstart, use {doc}`/guides/gazebo-envpool` to step several RL
environments together, or {doc}`/guides/direct-server` to build your own
control loop.
